# ShellPilot

GitHub Copilot in your PowerShell terminal: device-flow authentication, model
listing, chat, and agentic tool-calling with usage and cost reporting.

This wiki is generated automatically from the module source. It documents
ShellPilot version **#.#.#**.

## Getting started

```powershell
Install-Module -Name ShellPilot
Initialize-Shp                       # sign in with the GitHub device-code flow
Invoke-Shp 'Summarise what this repository does'
```
